APK — отдельная Android-установка конструктора. Для каждого нового проекта экспорт в отдельный APK ещё требует следующего этапа.

01 / Опиши свою идею

Чем точнее описание, тем полезнее получится прототип.

Честно о бесплатном режиме: здесь работает локальный генератор шаблонов — он не подключён к платному AI API. Для сложного приложения можно получить улучшенный промпт и использовать его в ChatGPT или другом ИИ, затем загрузить полученный код.

Скачанный HTML — веб-прототип, а не APK. Кнопка «Скачать APK конструктора» устанавливает само приложение A.S. APP BUILDER. Упаковка каждого сгенерированного проекта в отдельный APK автоматизируется на следующем этапе.






03 / Установка на Android
Есть два варианта: установить сайт как приложение (PWA) или скачать APK-файл конструктора. Android всегда попросит подтвердить установку APK; сайт не может устанавливать приложения незаметно.
ВАРИАНТ A
Установить сайт
Нажми «Установить сайт». В Chrome на Android может появиться системное предложение. Если кнопка не поддерживается, открой меню ⋮ и выбери «Установить приложение» или «Добавить на главный экран».
ВАРИАНТ B
Скачать APK
Нажми «Скачать APK конструктора». После загрузки открой файл из уведомления или папки «Загрузки» и подтверди установку, если Android запросит разрешение.
ВАЖНО
APK отдельного проекта
Текущая кнопка скачивает сам конструктор. Автоматическая сборка любого введённого пользователем проекта в отдельный APK ещё не реализована и требует безопасного сервера или авторизованного процесса сборки.
04 / Как получить APK бесплатно
Пока сайт не может безопасно запускать сборку на GitHub автоматически: для этого нужен защищённый сервер или авторизация. Не вставляй секретный GitHub-токен в публичную страницу.


ШАГ 01
Скачай HTML
Нажми «Скачать HTML». Это готовый прототип, который можно открыть в браузере и проверить.


ШАГ 02
Добавь его в Android-проект
В своём репозитории замени файл app/src/main/assets/index.html на скачанный HTML и сохрани изменения.


ШАГ 03
Запусти сборку
Открой вкладку Actions в репозитории, выбери Build Android APK и запусти workflow. После успешной сборки скачай APK из Artifacts.
