# Предложения — тренажёр русского языка

Учебный проект: веб-сайт и Android-приложение для составления русских предложений.

## Что уже есть
- выбор подлежащего, сказуемого, дополнения, места и времени;
- генерация и случайные примеры предложений;
- копирование результата;
- адаптивный интерфейс для телефона;
- Android-оболочка с локальной HTML-страницей — базовые упражнения доступны без интернета;
- GitHub Actions workflow для сборки APK.

## Сборка Android APK
1. Открой вкладку **Actions** в репозитории.
2. Выбери workflow **Build Android APK** и дождись успешного завершения.
3. Открой завершённый запуск и скачай артефакт **Predlozheniya-Android-APK**.
4. Распакуй ZIP и установи `app-debug.apk` на Android. При необходимости разреши установку приложений из этого источника.

Это тестовая debug-сборка для личного использования, не подписанный релиз для Google Play.

## Веб-сайт
Главная страница — `index.html`. Публикация через GitHub Pages настроена workflow-файлом `.github/workflows/deploy-pages.yml`; в настройках репозитория в разделе **Settings → Pages** необходимо выбрать источник **GitHub Actions**, если Pages ещё не включён.
