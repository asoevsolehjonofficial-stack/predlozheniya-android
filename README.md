# A.S. APP BUILDER

**Your Idea. Your App. Your APK.**

Бесплатный MVP сайта для подготовки прототипов приложений, игр и сайтов по текстовому описанию. Интерфейс адаптирован для мобильных устройств.

## Что уже реализовано
- выбор типа проекта: Android-приложение, игра или сайт;
- поле промпта и дополнительные требования;
- локальная генерация небольших HTML-прототипов по шаблонам;
- предпросмотр результата в изолированном iframe;
- просмотр и скачивание HTML-файла;
- генерация подробного технического задания для внешнего ИИ;
- инструкция по сборке тестового Android APK через существующий GitHub Actions workflow;
- старый тренажёр предложений сохранён в `predlozheniya.html`.

## Честные ограничения текущей версии
Это **MVP, а не полноценный автономный AI-сервис**. Публичная статическая страница не подключена к платному AI API и не может безопасно запускать сборку APK на GitHub без защищённого серверного компонента. Локальный генератор подбирает несколько базовых шаблонов. Для сложных приложений используйте кнопку копирования ТЗ, получите код в выбранном ИИ, а затем добавьте HTML в Android-проект.

Не размещайте GitHub Personal Access Token, пароли или API-ключи в HTML/JavaScript — посетители сайта смогут их прочитать.

## Как открыть сайт
1. Включите GitHub Pages: **Settings → Pages → Build and deployment → GitHub Actions**.
2. После публикации сайт будет доступен по адресу GitHub Pages этого репозитория.
3. Для проверки локально откройте `index.html` в браузере.

## Как получить APK из созданного HTML
1. Скачайте сгенерированный HTML.
2. В репозитории замените `app/src/main/assets/index.html` его содержимым.
3. Запустите workflow **Build Android APK** во вкладке **Actions**.
4. После успешного запуска скачайте artifact **Predlozheniya-Android-APK** и извлеките `app-debug.apk`.

Это тестовая debug-сборка. Для установки на устройство может потребоваться разрешить установку APK из выбранного источника. Название Android-приложения и package ID пока берутся из настроек существующего Android-проекта.

## Структура
- `index.html` — интерфейс A.S. APP BUILDER;
- `predlozheniya.html` — прежний веб-тренажёр русских предложений;
- `app/` — существующая Android WebView-оболочка;
- `.github/workflows/build-apk.yml` — сборка APK;
- `.github/workflows/deploy-pages.yml` — публикация сайта.

## Установка сайта и скачивание APK
- PWA: `manifest.webmanifest`, `service-worker.js` и `icon.svg` позволяют поддерживаемым браузерам предложить установку сайта на главный экран и кэшируют основные файлы для офлайн-открытия.
- APK конструктора публикуется GitHub Actions как релиз с тегом `latest-apk`. После успешной сборки прямая ссылка: https://github.com/asoevsolehjonofficial-stack/predlozheniya-android/releases/download/latest-apk/app-debug.apk
- Workflow запускается автоматически при push в `main` и вручную из Actions. Для публикации релиза ему требуется `contents: write`.
- Android требует, чтобы пользователь сам открыл загруженный APK и подтвердил установку. Веб-сайт не может устанавливать APK без согласия пользователя.
- Важно: эта ссылка скачивает APK самого конструктора. Сборка отдельного APK для каждого произвольного промпта ещё не реализована; статическая GitHub Pages-страница не имеет безопасного права запускать сборку с произвольными загруженными файлами.
