# Предложения — тренажёр русского языка

Учебный проект: адаптивный веб-сайт и Android-приложение для тренировки построения русских предложений.

## Возможности
- выбор подлежащего: «я», «ты», «он», «она», «мы», «дети» и другие;
- автоматическое изменение выбранного глагола по лицу и числу;
- добавление дополнения, места и времени;
- выбор точки, вопросительного или восклицательного знака;
- случайные примеры и подборка готовых предложений;
- копирование готового предложения;
- сброс выбора к начальным настройкам;
- адаптивный интерфейс для телефона;
- Android-оболочка с локальной HTML-страницей: базовые упражнения доступны без интернета.

> Конструктор предназначен для тренировки. После составления проверь смысл и естественность сочетания слов: не каждый глагол подходит к каждому дополнению.

## Скачать Android-приложение
1. Открой вкладку **Actions** в репозитории.
2. Выбери успешный запуск workflow **Build Android APK**.
3. В разделе **Artifacts** скачай **Predlozheniya-Android-APK**.
4. Распакуй ZIP и установи `app-debug.apk` на Android. Если система попросит, разреши установку приложений из используемого источника.

Это тестовая debug-сборка для проверки на Android, а не подписанный релиз для Google Play.

## Веб-сайт
Главная страница — `index.html`. Workflow публикации находится в `.github/workflows/deploy-pages.yml`. Если GitHub Pages ещё не активирован, открой **Settings → Pages** и выбери **GitHub Actions** в поле **Build and deployment → Source**.

## Технологии
- HTML, CSS и JavaScript;
- Android WebView;
- GitHub Actions для автоматической сборки APK и публикации сайта.
