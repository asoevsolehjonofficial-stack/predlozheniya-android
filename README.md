# A.S. APP BUILDER

**Your Idea. Your App. Your APK.**

Бесплатный MVP конструктора прототипов приложений, игр и сайтов по текстовому описанию. Интерфейс адаптирован для мобильных устройств.

## Что реализовано

- выбор типа проекта: Android-приложение, игра или сайт;
- генерация небольших HTML-прототипов по встроенным шаблонам;
- предпросмотр, просмотр и скачивание HTML;
- экспорт PWA-пакета в ZIP;
- создание технического задания для внешнего ИИ;
- Android WebView-оболочка и workflow сборки APK конструктора;
- защищённый Cloudflare Worker для очереди сборки APK с сайта;
- проверка входного HTML, Turnstile, ограничение частоты запросов и проверка целостности APK;
- автоматические проверки качества и безопасности через GitHub Actions.

## Честные ограничения текущей версии

Это **MVP, а не полноценный автономный AI-сервис**. Генерация прототипов на сайте основана на встроенных шаблонах; полноценное подключение моделей ИИ для генерации и изменения кода ещё не реализовано.

APK отдельного проекта — это **debug/test APK**, упаковывающий HTML/CSS/JavaScript в существующую Android WebView-оболочку. Конструктор не генерирует автоматически произвольные нативные Android-приложения, Android API, библиотеки или игровые движки.

### Как работает сборка APK с сайта

1. В браузере пользователь описывает проект и получает HTML-прототип.
2. При сборке сервер проверяет Turnstile и ограничения запроса.
3. HTML временно помещается в Cloudflare KV.
4. GitHub Actions запускает очередь примерно раз в пять минут и получает задание через короткоживущий GitHub OIDC-токен.
5. Сборщик проверяет HTML, создаёт debug APK и проверяет подпись/контрольную сумму.
6. APK временно хранится в KV и выдаётся только с токеном доступа к конкретному заданию.

Текущие ограничения backend: HTML до 1 MiB, тело запроса до 6 MiB, APK до 18 MiB; ориентировочные лимиты — не более 2 запросов на IP в час и 10 сборок в сутки. KV — временное хранилище, а не долговременная библиотека проектов. Лимиты и доступность зависят от тарифов провайдеров.

**Важно:** в текущей реализации APK хранится в KV в кодировке Base64; R2 не требуется. Секрет Turnstile хранится как секрет Cloudflare Worker. Не помещайте секреты, пароли и API-ключи в HTML, GitHub-файлы или публичные логи.

## Как получить APK самого конструктора

Workflow **Build and publish A.S. APP BUILDER APK** собирает APK конструктора и публикует его в GitHub Release с тегом `latest-apk`.

Ссылка на последнюю опубликованную сборку:
https://github.com/asoevsolehjonofficial-stack/predlozheniya-android/releases/download/latest-apk/app-debug.apk

Это тестовая сборка. Для бесшовных обновлений нужен постоянный закрытый ключ подписи, сохранённый в защищённых GitHub Actions secrets; пока его наличие не подтверждено, не следует рассчитывать на обновление поверх предыдущей версии.

## Файлы проекта

- `index.html` — интерфейс конструктора;
- `predlozheniya.html` — тренажёр предложений;
- `app/` — Android WebView-оболочка;
- `backend/src/index.js` — API очереди, статуса и выдачи APK;
- `backend/wrangler.toml` — конфигурация Worker и KV;
- `.github/workflows/build-apk.yml` — сборка APK конструктора;
- `.github/workflows/build-user-project-apk.yml` — очередь сборки пользовательских проектов;
- `.github/workflows/validate-web.yml` — проверки сайта и регрессионные тесты backend;
- `.github/workflows/quality-security.yml` — дополнительные проверки безопасности и Android/WebView.

## Проверки и готовность

После изменений в backend выполняются GitHub Actions для проверки синтаксиса, конфигурации, безопасности и регрессионных тестов. Последние проверки после ограничения размера тела запроса завершились успешно:

- Validate web app: https://github.com/asoevsolehjonofficial-stack/predlozheniya-android/actions/runs/38854594762
- Quality and security checks: https://github.com/asoevsolehjonofficial-stack/predlozheniya-android/actions/runs/38854588167

Эти проверки не заменяют сквозное испытание реального запроса через сайт и установку APK на Android-телефон.
