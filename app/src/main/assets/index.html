03 / Установка на Android
Есть два варианта: установить сайт как приложение (PWA) или скачать APK-файл конструктора. Android всегда попросит подтвердить установку APK; сайт не может устанавливать приложения незаметно.
ВАРИАНТ A
Установить сайт
Нажми «Установить сайт». В Chrome на Android может появиться системное предложение. Если кнопка не поддерживается, открой меню ⋮ и выбери «Установить приложение» или «Добавить на главный экран».
ВАРИАНТ B
Скачать APK
Нажми «Скачать APK конструктора». После загрузки открой файл из уведомления или папки «Загрузки» и подтверди установку, если Android запросит разрешение.
ВАЖНО
APK отдельного проекта
Текущая кнопка скачивает сам конструктор. Для отдельного APK создай прототип, настрой защищённый сервер в блоке «Сборка APK проекта» и запусти сборку.
04 / Экспорт проекта

ШАГ 01
Проверь прототип
Создай проект и проверь его работу в окне предпросмотра.
ШАГ 02
Скачай файлы
Используй «Скачать HTML» для веб-версии или «Скачать PWA-пакет ZIP» для устанавливаемого веб-приложения.
СЛЕДУЮЩИЙ ЭТАП
Нативный APK
Если владелец развернул защищённый сервис сборки, готовый прототип можно отправить на сборку отдельного APK ниже.




  
05 / Сборка APK проекта

  
Отправляет готовый HTML в отдельный сервер сборки, создаёт изолированный временный проект, проверяет APK и возвращает файл для скачивания. Сборка доступна в веб-версии по HTTPS: локальный HTML-файл и Android-оболочка не могут пройти проверку Turnstile из-за ограничений происхождения. Не отправляй пароли, личные данные или секретные ключи.

  

  

  

  

  
Сервер сборки настроен. Нажми «Проверить сервер», затем пройди Cloudflare Turnstile и нажми «Собрать APK проекта».
