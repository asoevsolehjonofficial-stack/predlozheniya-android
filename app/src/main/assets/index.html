⬇ Скачать APK конструктора

APK — отдельная Android-установка конструктора. Для каждого нового проекта экспорт в отдельный APK ещё требует следующего этапа.

01 / Опиши свою идею

Чем точнее описание, тем полезнее получится прототип.

Прямое скачивание: после создания проекта нажми «Скачать проект на телефон (HTML)» — файл сохранится в загрузки телефона, его можно открыть в браузере. ZIP подготовит устанавливаемую PWA-версию, которую сначала нужно разместить на HTTPS-хостинге. Отдельный APK для каждого проекта пока не собирается автоматически. Бесплатный генератор работает локально и не подключён к платному AI API.

02 / Результат

Предварительный просмотр и экспорт

Ожидает идею
Твой результат появится здесь после нажатия «Создать прототип».




HTML — веб-прототип. Кнопка «Скачать PWA-пакет ZIP» подготовит файлы устанавливаемого веб-приложения; пакет нужно разместить на HTTPS-хостинге. APK по-прежнему относится к самому конструктору, а не к отдельному проекту.






03 / Установка на Android
Есть два варианта: установить сайт как приложение (PWA) или скачать APK-файл конструктора. Android всегда попросит подтвердить установку APK; сайт не может устанавливать приложения незаметно.
ВАРИАНТ A
Установить сайт
Нажми «Установить сайт». В Chrome на Android может появиться системное предложение. Если кнопка не поддерживается, открой меню ⋮ и выбери «Установить приложение» или «Добавить на главный экран».
ВАРИАНТ B
Скачать APK
Нажми «Скачать APK конструктора». После загрузки открой файл из уведомления или папки «Загрузки» и подтверди установку, если Android запросит разрешение.
ВАЖНО
APK отдельного проекта
Текущая кнопка скачивает сам конструктор. Автоматическая сборка любого введённого пользователем проекта в отдельный APK ещё не реализована и требует безопасного сервера или авторизованного процесса сборки.
04 / Экспорт проекта
Сейчас конструктор создаёт веб-прототипы и позволяет скачать исходный HTML или PWA-пакет. Автоматическая сборка отдельного нативного APK для каждого нового проекта пока не доступна.
ШАГ 01
Проверь прототип
Создай проект и проверь его работу в окне предпросмотра.
ШАГ 02
Скачай файлы
Используй «Скачать HTML» для веб-версии или «Скачать PWA-пакет ZIP» для устанавливаемого веб-приложения.
СЛЕДУЮЩИЙ ЭТАП
Нативный APK
Для отдельного APK проекта понадобится безопасный сервис сборки Android. Эта функция ещё разрабатывается.
